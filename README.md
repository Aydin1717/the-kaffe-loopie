# The Kaffe Loopie — Baku ☕🐾

A modern, responsive specialty coffee shop website & live kitchen/admin portal built for **The Kaffe Loopie** in Baku, Azerbaijan (45 Istiqlaliyyat Street).

## ✨ Features

- **Trilingual Support (AZ / EN / RU):** Seamless language switching across the entire experience.
- **Specialty Coffee & Kitchen Menu:** Filterable categories (*Specialty Coffee, All-Day Breakfast, Bakery & Desserts, Teas & Refreshers*), search bar, and dietary tags.
- **Direct WhatsApp Takeaway Bag:** Customers build their order and send it directly to the cafe's WhatsApp without delivery app commission fees.
- **Table & Sunday Workshop Booking:** Instant reservation modal with celebratory confetti and WhatsApp confirmation.
- **Resident Rescue Cats Section:** Tribute to the beloved resident cats (**Mila & Simba**) with visitor etiquette rules.
- **Interactive Google Maps Embed:** Live map centered on 45 Istiqlaliyyat St with directions, opening hours status, and copy address actions.
- **🍳 Staff & Kitchen Portal (Mətbəx / Admin):**
  - Live kitchen orders feed with status tracking (`Yeni` ➔ `Hazırlanır` ➔ `Hazırdır`).
  - Table reservations management with 1-click WhatsApp customer confirmation.
  - Daily sales metrics and test order simulator for demonstrations.

## 🛠️ Tech Stack

- **React 19**
- **Vite**
- **Vanilla CSS (Modern Scandinavian Design System)**
- **Lucide Icons**
- **Canvas Confetti**

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
